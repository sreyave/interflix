# InternFlix

A Netflix-inspired interactive internship portfolio.

## Main sections
- Home — official trailer + project catalogue
- Journey — Season 1 timeline
- What's Next — Season 2

## Original structure
Each project follows:
- Synopsis
- How It Plays
- Behind The System
- Cast & Technology
- My Role
- Behind The Scenes
- Watch

Use a live URL for deployed projects or a demo video for projects that are not deployed.
